# Xquik - X (Twitter) Data

[![Convex Component](https://www.convex.dev/components/badge/convex-xquik)](https://www.convex.dev/components/convex-xquik)

Raycast extension for Xquik, the X Twitter data API. Not affiliated with X Corp.

> Xquik is an independent third-party service. Not affiliated with X Corp.
> "Twitter" and "X" are trademarks of X Corp.

## What you get

- 12 commands that search posts and users, read profiles, replies, mentions & trends, and manage monitors.
- Your API key kept in Raycast's password preference.

## Use the commands

Open Raycast and type a command name. Raycast asks for your Xquik API key the first time.
Copy the key from the API Keys page of your Xquik dashboard. It starts with `xq_`.

| Command | What it does |
| --- | --- |
| Search Posts | Search all public X (Twitter) posts, with no date limit. |
| Advanced Search | Find X (Twitter) posts by author, date, engagement & media. |
| Search Users | Find X (Twitter) accounts by name or username. |
| Look Up Profile | Show an X (Twitter) profile with counts, links & contact details. |
| Get User Posts | List the latest posts from any public X (Twitter) account. |
| Get User Mentions | List public posts that mention any X (Twitter) account. |
| Look Up Post | Open an X (Twitter) post from its link or ID. |
| Get Post Replies | List the replies to any X (Twitter) post. |
| Check Follow | Check whether 1 X (Twitter) account follows another. |
| View Trends | See what's trending on X (Twitter) by country. |
| Manage Monitors | Create, pause & delete X (Twitter) account and keyword monitors. |
| View Monitor Events | Read the latest events from your monitors. |

## Search with operators

Search Posts accepts X search operators. Type a query like this one.

```text
"twitter api" min_faves:10 since:2026-10-01
```
